## About

This repository contains the official landing page for *Speak Generative AI*, a
practical, jargon-free guide to prompt engineering for people who don't write
code. The book shows you how to communicate clearly with large language models
(LLMs) and write prompts that get better results.

🌐 **Live site:** https://prompt-engineering-book-intro.vercel.app/

📖 **Get the book:** [Amazon](https://www.amazon.com/dp/B0HDR4W53H)

## About the site

- A single static page (`index.html`), no build step or dependencies
- Responsive layout for desktop and mobile
- Deployed on [Vercel](https://vercel.com)

## Run locally

Open `index.html` in any browser. No server or installation is needed.
